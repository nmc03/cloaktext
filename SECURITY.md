# Security policy

[Versión en español más abajo.](#política-de-seguridad)

## Supported versions

The `main` branch and the latest stable release receive security fixes.

## Reporting a vulnerability

Do not open a public issue for a vulnerability that could expose data, allow code execution or break the privacy model.

Use **Report a vulnerability** in the repository's *Security* tab (private vulnerability reporting). Include minimal reproduction steps and avoid attaching real personal information.

Do not send:

- real texts or documents containing sensitive data;
- restore keys generated by the application (`cloaktext.json`);
- keys, tokens or credentials;
- memory dumps containing user content.

## Privacy model

CloakText processes content locally; see [PRIVACY.md](PRIVACY.md). The restore key contains the original data and must be protected like the original text.

Automatic anonymisation reduces accidental exposure but does not replace human review when content will be shared with third parties.

# Política de seguridad

## Versiones soportadas

La rama `main` y la versión estable más reciente reciben correcciones de seguridad.

## Notificar una vulnerabilidad

No abras un issue público para una vulnerabilidad que pueda exponer datos, permitir la ejecución de código o comprometer el modelo de privacidad.

Usa **Report a vulnerability** en la pestaña *Security* del repositorio (informe privado de vulnerabilidades). Incluye pasos de reproducción mínimos y evita adjuntar información personal real.

No envíes:

- textos o documentos reales con datos sensibles;
- claves de restauración generadas por la aplicación (`cloaktext.json`);
- claves, tokens o credenciales;
- volcados de memoria con contenido de usuario.

## Modelo de privacidad

CloakText procesa el contenido localmente; consulta [PRIVACY.md](PRIVACY.md). La clave de restauración contiene los datos originales y debe protegerse como el texto original.

La anonimización automática reduce la exposición accidental, pero no sustituye la revisión humana cuando el contenido vaya a compartirse con terceros.
