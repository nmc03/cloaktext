# Política de seguridad

## Versiones soportadas

La rama main y la versión estable más reciente reciben correcciones de seguridad.

## Notificar una vulnerabilidad

No abras un issue público para una vulnerabilidad que pueda exponer datos, permitir ejecución de código o comprometer el modelo de privacidad.

Usa la opción Report a vulnerability de la pestaña Security del repositorio cuando esté disponible. Incluye pasos de reproducción mínimos y evita adjuntar información personal real.

No envíes:

- textos o documentos reales con datos sensibles;
- claves de restauración generados por la aplicación;
- claves, tokens o credenciales;
- volcados de memoria con contenido de usuario.

## Modelo de privacidad

CloakText procesa el contenido localmente. El clave de restauración contiene los datos originales y debe protegerse con el mismo nivel que el texto original.

La anonimización automática reduce exposición accidental, pero no sustituye una revisión humana cuando el contenido vaya a compartirse con terceros.
